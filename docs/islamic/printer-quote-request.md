# طلب عرض سعر طباعة — سلسلة «قلبي يعرف الله»

مرحبًا،

نرجو عرض سعر لطباعة سلسلة كتب أنشطة وقصص للأطفال بالمواصفات التالية. كل نسخة شخصية (اسم الطفل وشخصيته المرسومة على الغلاف وفي الجواز والشهادة)، وفيها صفحات فيها كلام الله تعالى وأذكار، فنحرص على جودة الطباعة ومتانة التجليد حتى لا تتفكّك الصفحات.

## المواصفات

- **المقاس:** 21×28 سم عموديًا، أو A4 (21×29.7 سم). نعتمد A4 إذا كانت قوالبكم A4. أخبرونا بالمقاس الذي يوفّر عليكم الهدر.
- **عدد الكتب:** خمسة مجلدات بين 98 و120 صفحة، وكتاب موسمي نحو 70 صفحة. نرجو السعر لأربع فئات: 70 و100 و112 و120 صفحة، طباعة ملوّنة كاملة على الوجهين. ورق أوفست غير مطليّ، نرجو السعر لخيارين: 120 غم و140 غم.
- **الغلاف:** كرتون 300 إلى 350 غم، طباعة ملوّنة، سلفنة مطفية على الوجه الخارجي. ونرجو سعرًا إضافيًا للغلاف المقوّى (هارد كفر) للمجموعة الهدية.
- **التجليد:** نرجو السعر لخيارين:
  1. **غلاف ورقي لاصق (Perfect-bound)** بتخييط أو بغراء قوي، نفضّل ما يتحمّل الفتح المتكرر دون أن تنفكّ الأوراق. نرجو ذكر الهامش المطلوب عند كعب الكتاب (التجليد) لنوسّعه في الصفحات التي يكتب فيها الطفل.
  2. **سلك حلزوني (Wire-O)** على الحافة الطويلة.
- **ملحق اختياري:** ورقة ملصقات A4 ورق لاصق مطفي، طباعة ملوّنة، مع قصّ نصفي (kiss-cut). نرجو سعرها منفصلًا.

## الكميات

نرجو **سعر النسخة ومجموع الطلبية ومدة التنفيذ** لكل كمية، لمجلد 112 صفحة (ونرجو الفرق للفئات الأخرى):

| عدد النسخ | ورق 120 غم: لاصق | ورق 140 غم: لاصق | ورق 140 غم: حلزوني |
|---|---|---|---|
| 1 | | | |
| 10 | | | |
| 50 | | | |
| 100 | | | |
| 500 | | | |

- للكميات الكبيرة: هل تنصحون بالأوفست؟ إن كان كذلك نرجو تكلفة التجهيز الثابتة (الألواح وضبط الماكينة) وسعر النسخة.
- سعر نسخة تجريبية مطبوعة (بروفة) قبل أول طلبية، فنحن نعرضها على مشرف علمي وعلى عائلات قبل الطباعة.
- هل تقبلون طباعة نسخ **مختلفة الغلاف** (كل نسخة باسم طفل وشخصيته) في طلبية واحدة؟ وما الكمية الدنيا؟ وهل تكلفة تغيير الغلاف بين نسخة وأخرى (طباعة رقمية) مختلفة عن الأوفست؟
- تكلفة التوصيل إلى رام الله والبيرة، أو الاستلام من المطبعة.

## الملفات

نسلّم ملفات PDF جاهزة للطباعة بألوان CMYK وهامش قصّ 3 مم، الصفحات الداخلية في ملف والغلاف في ملف مستقل. نرجو إرسال:
- قوالبكم للتجليد (عرض الكعب حسب عدد الصفحات والورق) وخطوط القصّ للملصقات؛
- ملف ألوان الطباعة (ICC profile) الذي تستعملونه، إن وُجد؛
- أي شروط أخرى للملفات.
