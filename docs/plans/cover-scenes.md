# Cover scenes: one illustrated scene per part

2026-10-09. The owner asked for covers that look professional and show what is inside each part
(«بدنا اشي أكثر احترافية وبنفس الوقت بحتوي على رسومات أو مشاهد تعكس محتوى الكتاب»). The covers of the four
activity series are now a layered composition in code (`packages/workbook/src/qamra_workbook/render/covers.py`):

1. **Scene** (this plan): one full-bleed picture per part, with a calm top for the title and an empty, lit spot
   where the child's own character is composited. The picture has **no text and no people**.
2. **Props** (code, SVG): the part's real letters and numbers as toy blocks, lanterns, stars and so on.
3. **Child** (code): the approved character, cut out with its white sticker edge.
4. **Lettering and badges** (code): every word on a cover is set in code, never drawn by the image model.

Until a part's scene is installed, its cover composites the older plates (`content/assets/G*`, `F5`–`F10`) or
a vector scene, so every cover is complete without this step.

## The scenes and their cost

- **Model:** Nano Banana Pro on fal (`fal-ai/nano-banana-pro`, text to image), checked on 2026-10-09:
  `aspect_ratio` 3:4, `resolution` 2K (about 1792 × 2400 px), $0.15 per image at 1K and 2K, $0.30 at 4K.
  Commercial use is allowed through fal. Nano Banana Pro follows long layout instructions better than
  Nano Banana 2 ($0.12 at 2K), and a cover is worth the extra 3 cents.
- **House style:** one style paragraph in every prompt (polished stylized 3D, soft rounded shapes, bright
  saturated colors on a light base), so the 16 scenes read as one family and sit well behind the 3D
  characters. Every prompt also carries the layout (calm top, empty lit spot, framed corners), the
  Levantine setting cues and the rules: no people, no text. The Islamic scenes add the series' rule (no
  depiction of God, a prophet, an angel or a Companion in any form; no Quran writing).
- **Size in print:** the plate is cropped to the cover with its bleed and resampled to 300 DPI
  (A4 + bleed = 2551 × 3579 px; 21 × 28 + bleed = 2551 × 3378 px). At 2K that is about 210 DPI of real
  detail, the same as the Islamic covers already printed. 4K would double the price.
- **Cost:** 16 scenes × $0.15 = **$2.40**. With one retry for about half of them (an image that shows text, a
  person, a melted object or a crowded centre): **about $3.60**. Hard cap for this work: **$5.50** (owner,
  2026-10-09), counted from the `cover-scenes:` rows of `out/design-images/ledger.jsonl`.

## Review before installing

Read every image at full size and at phone size. Reject and redraw when:
- any text, letter, number or writing-like mark appears (blocks, books, boards, signs, rugs);
- a person, a face, a hand, a figure or a silhouette appears (Islamic scenes: anything that could read as a
  sacred figure);
- objects melt into each other, a shape is broken, or the middle spot is not empty and lit;
- the top third is busy (the title will sit there).

## Commands

```bash
# what would be drawn, and the money left under the cap
uv run python scripts/cover_scenes.py --dry-run
# draw (a scene that exists in design/incoming/cover-scenes/ is skipped)
uv run python scripts/cover_scenes.py --budget 5.5 [--only kg1-v1 islamic-r]
# draw another version of a scene (saved as <id>-2.png, <id>-3.png …)
uv run python scripts/cover_scenes.py --budget 5.5 --again kg1-v1
# install the chosen version: content/covers/scenes/<id>.jpg (JPEG 90), read by every cover of that part
uv run python scripts/cover_scenes.py --install kg1-v1 [kg1-v1-2.png]
```

The covers pick the installed scene by its id (`covers.SCENES`); nothing else changes. Re-export the web
previews after installing (`uv run python scripts/export_workbook_previews.py --render`).
