# Phase 4 — Kindergarten portal (outline)

Changes from Addendum 1 — «كتاب الصف» is the core product:
- Class book: shared story pages with 3–5 child slots each + per-child portrait page + class group page + teacher message + school logo, plus a personal cover per child.
- Auto-assignment of children to slots (every child ≥ N appearances, default 2, balanced) + drag-and-drop page planner.
- Multi-character references per image, capped per provider (config, start at 3). Flag pages where a child is not recognizable.
- Print bundle: N interiors + N covers + portrait page inserted per copy; `{school}-{class}-{child}.pdf` + combined print file.
- Teacher status board: invited / consent / photo / drawing / character approved.
- `class_book` per-child pricing with volume tiers (admin configurable).
- Accept: class of 25 → complete bundle, every child ≥ 2 appearances, review queue shows per-child coverage.
