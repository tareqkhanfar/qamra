# Addendum 1 — Design for Qamra (قمرة): rename + new feature screens > Give this to Claude in the SAME design conversation after the first design is done. Keep the existing design system; only rebrand and add what is listed here. --- ## 1. Rebrand to «قمرة» (Qamra) - Replace the name everywhere with **قمرة** / **Qamra**. - Meaning: «ليالي القمرة» — moonlit Palestinian/Levantine evenings when the family gathers and the grandmother tells stories. - Tagline: «حكاية طفلك… تحت ضوء القمر». - **Logo**: design 3 options for a wordmark «قمرة» with a moon mark (e.g., a crescent that is also the curve of an open book page, or a full moon with a small star). Must work in one color, at 24px (favicon) and on the book spine/back cover. Provide Latin lockup "Qamra". - Adjust the palette if needed so it clearly reads "moonlight": deep night blue primary, warm moon-gold accent, cream paper. Keep AA contrast. - Add a subtle recurring motif: moon phases (can be used as a progress indicator in the create flow — new moon → full moon as the book gets closer to done). ## 2. New screens — «رسمة طفلك صارت صاحبه» (drawing becomes the companion) This is the brand's signature feature. It must feel magical and be front and center. 1. **Landing page hero update**: show the transformation in 3 frames — child's photo, child's crayon drawing → both appear together as illustrated characters on a book page. Headline idea: «طفلك البطل… ورسمته صاحبه». Also add a short looping animation concept (describe frames) for Instagram. 2. **Create flow – new step "ارسم صاحبك"** (after the photo step): - Intro card explaining the idea with a before/after example; a clear "تخطّي" option. - Upload drawing (camera-first on mobile) with tips: white paper, good light, whole drawing in frame. - Cleaned drawing preview with crop handles. - Name the companion + type chips (مخلوق، حيوان، روبوت، غير ذلك). - Generating state (moon-phase progress). - Choose between 2 generated companions / regenerate; show the original drawing next to each option. 3. **Book page examples** with child + companion together, and the special **last page «وهكذا وُلد صاحبي»**: original drawing and final character side by side, child's name, date, framed like a keepsake. 4. **My companions** section in the parent account (reusable companions as cute cards). ## 3. New screens — «كتاب الصف» (class book, kindergarten portal, desktop-first) 1. **Class book setup**: choose theme, number of appearances per child, upload school logo, teacher message. 2. **Readiness board**: grid of children cards with status steps (دعوة، موافقة، صورة، رسمة، شخصية معتمدة), filters, "remind parents on WhatsApp" bulk action. 3. **Page planner**: book pages as columns, child avatars as draggable chips into scene slots; coverage meter per child (e.g., "سلمى: 3 مرات"), warnings for children with too few appearances. 4. **Review grid**: all generated pages with per-page flag/regenerate, per-child coverage check. 5. **Personal cover preview**: carousel of each child's personalized cover. 6. **Print bundle summary**: copies, price tiers, delivery to school, invoice. 7. Book layouts: class group page (all characters together), per-child portrait page, teacher message page. ## 4. New screens — «صوت أهلي» (family voice via QR) 1. **Record screen (mobile)**: large page text, big record button, waveform, listen / re-record, voice label chips (ماما، بابا، ستّي، سيدي), page progress. 2. **Invite a grandparent to record**: share link via WhatsApp, simple no-login recording page with very large text and buttons (designed for older users). 3. **Listener page** (opened from the QR in the printed book): shows the page illustration, play button, voice switcher. Must load fast and look beautiful on any phone. 4. **Print detail**: how the QR sits on the book page (small, bottom corner, inside safe area, with a tiny moon icon and «امسح واسمع»). ## 5. Marketing assets - 3 Instagram post templates and 2 story templates showing the drawing → companion transformation. - A one-page flyer (A5) for kindergartens about the class book. ## 6. Handoff Same as before: export new/changed screens as HTML + Tailwind (RTL), update `tokens.json` and the logo files (SVG), and list all new screens in the `README.md` under "Addendum 1".
